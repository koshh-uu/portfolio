# Интерактивное портфолио команды

Командный проект для участия в крупном IT-форуме. Презентационная страница
из **5 интерактивных карточек** участников, где каждый раскрывает свою
личность через современные веб-технологии.

🔗 **Демо:** [открыть сайт](https://koshh-uu.github.io/portfolio/)

## Стек технологий

- **HTML5** — семантическая разметка
- **CSS3** — Grid, Flexbox, анимации, `aspect-ratio`, кастомные свойства
- **JavaScript (Vanilla)** — без библиотек и фреймворков
- **Google Fonts** — Unbounded, Lora, JetBrains Mono
- **Canvas API** — анимированный фон-частицы

## Реализованный функционал

### Контент
- 5 карточек участников
- От 1 до 3 фотографий на человека (авто-слайдер)
- Краткое «О себе»
- Любимая цитата, визуально выделена
- Автоматический расчёт возраста: **годы + месяцы + дни + секунды**

### Wow-эффекты
-  **3D Tilt Effect** — карточка наклоняется вслед за курсором
-  **Typewriter Effect** — цитата печатается как в терминале
-  **Плавное переключение** карточек (стрелки, точки, клавиатура, свайпы)
-  **Слайдер фото** с автопрокруткой и паузой при наведении

### Пасхалки
- 🐛 **Konami Code** (`↑ ↑ ↓ ↓ ← → ← → B A`) — цитата меняется на мемную, экран инвертируется
-  **3 клика по логотипу** — секретный режим с частицами, реагирующими на курсор

## Подготовка фотографий

| Параметр | Рекомендация |
|----------|--------------|
| Пропорции | 4:5 (портрет), допускается 3:4 или 1:1 |
| Размер | 800×1000 … 1200×1500 px |
| Формат | `.jpg` или `.webp` |
| Вес | до 300 КБ на фото |

Имена файлов должны совпадать с путями в `index.html`:
`images/photo1.jpg`, `images/photo2.jpg` и т.д.
